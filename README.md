# 馨馨的小盒子

一个可以部署到 GitHub Pages 的静态小站。原生 HTML / CSS / JavaScript，自带本地 SVG 插画，无构建步骤、无第三方运行时依赖、无数据上传和访问统计。

## 本地预览

在本目录使用 Node.js 启动自带的预览服务：

```sh
node scripts/serve.cjs
```

打开 `http://127.0.0.1:4173`。也可以使用其他静态 HTTP 服务。直接双击 `index.html` 也能查看插画和体验互动，但不要用这种方式验收本地存储，不同浏览器对 `file:` 地址的存储行为不一致。

## GitHub Pages 部署

1. 将此目录文件提交到你选择的 GitHub 仓库，包括 `.nojekyll`、页面、脚本和样式文件。当前页面图标与雨滴均已内嵌，不依赖 `assets` 文件夹。
2. 在仓库 **Settings → Pages → Build and deployment** 中，选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/ (root)`，保存。若使用其他分支，选择实际提交代码的分支。
4. 等待 Pages 部署完成，打开设置页显示的网址。项目站通常是 `https://用户名.github.io/仓库名/`。
5. 在实际手机和常用浏览器（包括微信内置浏览器，如有使用）验收。

资源路径均为相对路径，兼容仓库子目录。普通 GitHub Free 的 Pages 使用公开仓库；普通 Pages 发布页面可被他人访问。`noindex` 仅请求搜索引擎不要索引，不是访问控制。

## 维护内容

编辑 `content.js`，即可修改昵称、纸条、小雨点彩蛋及未来信。`interactions` 集中保存插画互动短话、提示、页脚和雨滴落款。

- **纸条 ID 保持稳定且唯一**。修改错字可沿用 ID，新纸条应使用新 ID。收藏按 ID 保存；暂时下架的纸条保留收藏标记，恢复同一 ID 后可再次显示。
- `letters` 默认为空，因此未来信入口隐藏。加入包含 `id`、`title`、`unlockAt`、`text` 的对象即可显示。
- `unlockAt` 必须包含明确时区，例如 `2027-01-01T09:00:00+08:00`。页面按设备时钟判断是否到期；到期后重新打开信件抽屉即可看到，抽屉保持打开时每 30 秒检查一次。
- 未来信正文实际包含在公开文件中，日期限制不是加密。不要提交私密素材、真实聊天记录、凭证、工作单位或其他不适合公开的信息。
- 当前没有照片、录音、AI、发送消息、跨设备同步或主动通知功能。

## 插画和拆纸条

- 花、信件、盒身、爱心和雨滴都可以点击，也支持键盘。前四项分别播放花瓣、纸飞机、打包与小爱心动画；短话显示在插画下方，不弹窗、不播放声音。新点击会清理前一个效果。
- 画面各部件以 SVG 分组直接内嵌在 `index.html` 中，避免 `file:` 打开时跨文件 SVG 引用被浏览器限制；保留原画构图和互动。动画样式单独放在 `interactions.css`。
- 每次从首页进入拆纸条，先选三张背面纸条中的一张。读完可以直接再拆，或回盒子重新选。未选或动画中关闭不消耗留言；收藏仍按原有 ID 保存。
- 系统设置为减少动画时，互动短话和纸条即时显示，不播放花瓣、飞行、打包或纸条展开动画。

## 窗边小景

- 窗台放着一盆小绿植，窗外可选择雨天、阴天、晴天，不播放声音。天气通过约一秒的颜色与透明度变化切换；绿植保持静止，雨和云仅作轻微运动。
- “暂停动画”控制整个场景，暂停时收起雨滴，天气仍可即时切换。系统减少动画时使用静态画面。关闭弹窗或进入后台会停止运动，返回时按原偏好恢复。
- 天气默认雨天，只在主动选择后保存。天气键为 `lucky-everyday:xinxin:v1:weather`，值为 `rain`、`cloudy`、`sunny`；旧 `rain-paused` 键继续表示动画暂停，不改变旧数据含义。不能保存时，本次操作仍有效，并显示提示。
- 场景使用内嵌 SVG，样式在 `quiet.css`。`content.js` 的 `quiet` 配置维护天气名称、场景说明和按钮文案。

## 本地数据

使用 `lucky-everyday:xinxin:v1:` 前缀保存收藏 ID、主动选择留下的树洞、场景暂停和天气偏好。树洞默认不保存；未提交的输入仅留在当前页面内存，关闭抽屉后再次打开可继续写，刷新或离开后不保证保留。

保存成功才清除输入；写入失败会保留内容并提示。读取失败或数据格式损坏时，页面不自动覆盖原有数据，并暂停写入，避免误删旧记录。可先使用不保存的功能，再检查浏览器限制或先备份网站存储。

记录不是加密保险箱；共享浏览器的使用者可能查看。清理网站数据、无痕会话结束、换浏览器或域名均可能导致记录无法恢复。GitHub 同域不同项目仍共享 origin，本项目通过键名前缀避免常规冲突，不提供项目间安全隔离。

## 验收清单

- 手机 320 / 390 CSS px 和桌面：无横向溢出、按钮可点、长中文能换行。
- 纸条：一轮全部内容不重复、跨轮不连续重复、收藏刷新后存在、取消收藏正确。
- 树洞：不保存时提交后刷新消失；勾选保存后可读、可单删、清空需确认；写入失败不清空输入、不显示成功。
- 支持中文输入法组合输入，不在输入过程中改写内容；纸条或树洞中的 HTML 字符显示为纯文本。
- 弹窗支持 Tab、Shift+Tab、Escape，关闭后焦点回到入口；小雨滴可通过键盘打开。
- 检查插画各入口至少约 44px、无重叠遮挡；连续点击不堆积动画；关闭纸条弹窗后无延迟揭晓；回盒子及再次进入正确重置选择界面。
- 检查三种天气、快速切换、暂停后换天气、旧暂停记录兼容、减少动画、关闭及后台停止；查看手机和桌面截图，矮屏弹窗可滚动。
- 未来信空配置隐藏；测试日期前、等于日期、日期后，以及无效日期被忽略。
- 部署到仓库子目录，检查 CSS、JS、SVG 都成功加载；查看 Network，确认没有第三方请求或输入上传。

自动化浏览器检查脚本见 `tests/browser.cjs`，需外部提供 Playwright（不作为网页运行依赖）。运行方式见脚本头部。

浏览器可使用 Playwright 安装的 Chromium，或通过 `BROWSER_EXECUTABLE` 指定已有 Chromium / Edge 的可执行文件。检查会临时启动本地服务，将截图写入已忽略的 `test-results/`，不会修改内容配置。

手机图标使用内嵌 SVG 路径，避免星形、信封、雨伞、箭头被系统字体显示成 Emoji。雨滴和弹窗雨滴同样内嵌，网站图标采用 SVG data URL，不需要额外的图片请求。
