# 馨馨的小瓶子

一个送给馨馨的静态小站：接住小雨滴带来的话，和它倾诉，或者在窗边坐一会儿。米白、灰绿、手绘 SVG；原生 HTML / CSS / JavaScript，无构建步骤、第三方运行时、数据上传或访问统计。

## 本地预览与发布

```sh
node scripts/serve.cjs
```

打开 `http://127.0.0.1:4173/`。服务只监听本机，也支持 `/LuckyXinxin/` 子目录验收。不要用 `file:` 地址验收存储，不同浏览器行为不一致。

发布时提交 HTML、`content.js`、`art.js`、`app.js`、四个 CSS（含 `desk.css`）、`assets/` 与 `.nojekyll`，在 GitHub Settings → Pages 选择分支和根目录。所有资源路径为相对路径；发布后仍需真实手机检查。本站没有离线缓存。

## 首页小桌面

- 小瓶子缩小放在欢迎语旁，礼物盒在下方独立居中，小羊从盒子右下方探头；保留信纸、信封、花和爱心。首次与回访均显示介绍。
- 手机依次显示欢迎与小瓶子、今日入口、三个功能入口、礼物盒和收集瓶架。八个场景按钮与页尾星星均至少44×44px，回应预留空间随文字放大重排；不再显示“点瓶子看看”或桌面探索提示。
- 原盒子SVG和动画从Git旧版恢复：点盒子打包，点信封折出纸飞机，点花轻摇并落下满屏花瓣，点爱心轻跳并飘出爱心。小羊缩小藏在盒后，点按出现小小的漫画“Lucky～⭐”气泡；页尾星星点按泛光闪烁。主瓶打开收集菜单，小雨滴打开悄悄话。所有互动无声音。
- 彩蛋运动约1–2秒、回应约4秒；连点会替换上一段，打开弹窗或切后台清理运动与回应。系统减少动画时只显示静态回应，切换偏好时保留当前回应至原定结束时间。彩蛋不保存数据、不发送消息、不消耗随机内容或增加收藏。
- 主瓶数量更新只重绘瓶内内容；盒子、星星、小雨滴及其按钮保持原节点。物件动作通过 `data-art` 统一绑定，便于后续扩展其他场景；本轮交互范围是首页。
- 随机入口叫“随手接一滴”；礼物盒下方到收藏区标题的间距缩短24px，彩蛋回应仍保留自然换行空间。新增提示及花的回应少量使用Emoji，不改写已保存的赠言和心事。

## 今日与随机雨滴

- “接住今天这一滴”首次播放约1.3秒的荷叶接住动画，落稳在叶面后自动保存当天赠言、日期和表情。当天再打开直接读已存快照，不重复播放、不重复增加。
- 首页按钮在当天成功保存后变为“看看今天留下的这一滴”。初始化、收藏增删、恢复、跨标签同步、本地午夜及回到前台会刷新状态；保存失败或中途关闭仍显示“接住今天这一滴”。
- 今日雨滴以设备当地 `YYYY-MM-DD` 为身份。同一句赠言在不同日期仍是不同纪念；同时可以另外作为普通雨滴收集。同一天已存的内容不随内容池编辑而变化。
- 今日页没有“再接一滴”，只保留结果状态和明确的“去随手接一滴”入口。保存失败时内容仍可读，显示重试；重试保留原日期、内容和表情。动画结束前关闭不会保存；动画完成时页面在后台则暂停这次接住，不在后台新增。
- 随机入口每次展示三滴不同表情的小雨滴，没有数字。六种表情是微笑、眯眼笑、困困、发呆、鼓脸、小委屈，只是形象，不推断或记录真实情绪。
- 选择后雨滴落在手绘荷叶中央，叶面轻轻下沉、回弹并停稳，再展示赠言。“接住啦”在接触后出现；随机阅读不自动保存。“存下这一滴”把文字和所选表情一次写入。“再接一滴”回到新的三滴选择区。
- 同一普通留言ID只存一滴，重复遇到不会替换瓶里原表情。瓶中重读始终使用保存时的内容和表情。随机每轮不重复、跨轮避免连续重复；关闭未完成的接住不消耗队列。今日和瓶中重读不消耗随机队列，只剩眼前那滴时会先明确标注“陪你再听一遍”重读另一滴。
- 系统减少动画时直接展示结果；今日仍由用户点击后保存，不在页面加载时收集。

## 超级幸运与瓶子彩蛋

- `content.js` 的 `superLucky` 只配置一份特殊文案，固定ID `super-lucky-01`，独立于64条普通赠言。22条原赠言各补一个符合句意的Emoji，已有Emoji与已保存的正文快照保留。
- 今日雨滴和随手接一滴共用一份连续未中计数。命中后恢复基础5%，允许连续命中，不再单独降低连中概率。连续15次未中后，第16/17/18/19/20次概率依次为10%/15%/20%/25%/30%，第21次为100%；长期出现率约7.93%。
- 只在承接动画完成、页面处于前台并展示新结果时抽取和计数，与是否收藏无关。随机命中不消耗普通赠言队列，保留本次选择的表情。关闭未完成动画，或动画完成时页面在后台，都不会抽取或推进计数；后台完成的今日承接会关闭，回到前台后可重新接住。瓶中重读、当天已有结果重读、保存及失败重试不推进计数。
- 今日雨滴不再使用日期散列独立判断幸运。当天已有收藏快照优先；新结果与共享计数同时写入本地进度，只缓存最近一次生成的今日快照，避免收藏失败后关闭、重开、刷新或切换入口时重抽。跨日首次接住才参与下一次抽取；普通今日赠言仍按当地日期轮换，不消耗随机赠言队列。
- 正常存储时刷新续接，依次在不同标签页接雨滴会读取最新进度，今日动画结束时也会优先读取其他标签页已保存的当天快照。存储不可用时在本页内继续计数和缓存，刷新后不保证保留。损坏进度不会被覆盖，也不影响既有收藏。旧版进度保留连续未中次数，移除连中次数，不从旧收藏倒推计数。
- 进度不记录逐次阅读历史，不显示保底进度；最近一次今日快照只是防止重抽的缓存，收藏失败时仍不计入瓶子。计数和缓存不包含在收藏备份中，恢复收藏不会改动当前进度；已保存的历史内容与金色标记不因新规则改变。
- 每日超级幸运仍一天自动保存一滴；主动接到的每次幸运相遇均有独立ID和时间，由用户手动保存。连点保存与失败重试使用同一个相遇ID，成功后才提示“超级幸运已放进瓶子里。✨”。它们都属于“送给你的”，继续按每瓶10滴分瓶。
- 新相遇播放约2.4秒满窗口金色星光，使用不接管焦点、不拦截点击的手动Popover顶层；不支持Popover时保留阅读卡片与背景的金色强调。关闭阅读窗口、切后台或切换减少动画设置都会清理庆祝。当天重读和瓶中重读仅保留静态金色阅读卡片、戴小皇冠的雨滴及相遇日期。
- 首页瓶架、收藏菜单、瓶子详情及首页当前展示的主瓶，只在实际含有特殊记录时增加金色水色与柔和光晕。取出后重新分瓶、恢复和跨标签同步都会重新计算；后台暂停呼吸光效，系统减少动画时保持静态。
- 左上角瓶子是44×44px的独立按钮。每点一次轻晃，相邻点击间隔不超过2秒，连续3次冒出约1.4秒星星并重置计数。支持触摸、Enter和空格；不显示操作说明，不保存数据、不增加收藏。打开弹窗或进入后台清理；减少动画时仅短暂显示静态星星。

## 收集瓶与弹窗

- 主瓶是收集菜单入口，使用原生按钮及可访问名称；不再重复设置文字跳转。菜单用“送给你的／留给自己的”切换分类。
- 首页只有一个混合瓶架，两类瓶子按瓶号交错排在一起，盖色和星星／小云标记区分类型。普通收集为空时展示一个空瓶，心事为空时不展示空瓶。
- 每类每瓶10滴，第11滴开第2瓶，第21滴开第3瓶；取出后重新分瓶。水位与星光分为1–3、4–6、7–9、10滴四阶段；瓶盖和水色随瓶号稳定变化，没有等级、打卡或连续天数。
- 首页与菜单每页最多6瓶；点具体瓶子再点其中最多10滴雨滴看全文。自己的心事不写进首页、瓶内预览或可访问名称，只在点开那滴时显示；关闭详情后移除正文。
- 所有弹窗采用固定标题与关闭区，只滚动正文。长赠言、私密详情、瓶架或说明滚到底部仍可关闭；Tab、Shift+Tab、Escape和嵌套焦点返回均保留。
- 雨滴统一用“滴”，幸运星仍用“颗”；弹窗标题不加末尾句号，正文正常使用标点。本轮文案调整不改写已存赠言快照或用户倾诉原文。
- 主按钮使用浅雾蓝与深色文字，次按钮使用暖米色；深灰绿保留为文字和少量强调。

## 倾诉与远行

- 默认不保存，未提交的输入只保留在当前页面内存；关闭再打开可以继续，刷新或离开不保证保留。
- 勾选“把这一滴留给自己”后，成功写入才清空输入、增加一滴。每次提交独立保存，记录包含一个形象表情；不根据倾诉文字判断情绪。失败时保留输入及选择，不显示成功。
- 不勾选则清空本次提交，并显示“小雨滴带着你的小情绪远行啦”，不写入存储、不增加数量。空输入不强迫提交。
- 约5秒的固定室内第一视角：近处提行李挥手、转身、越过房门与门槛、朝雨中远去；雨滴逐渐缩小、模糊并消失。单扇门宽高比约0.52，门板向屋内打开；地板与室外小路共用消失点，雨滴脚底沿地面远去，不向门洞上方漂移。全程无声音。
- 可跳过、可关闭；进入后台结束，返回不重播。减少动画时显示静态远行插画。私密雨滴取出需确认。

## 本地记录与兼容

旧的 `lucky-everyday:xinxin:v1:` 键继续兼容：

| 键 | 用途 |
|---|---|
| `favorites` | 旧留言ID数组。新赠言记录不存在时兼容读取，按ID生成稳定默认表情；转换成功后作为原样备份，不再当作当前收藏 |
| `vents` | 原 `{id,text,at}` 数组，可选 `expression` 字段；旧记录缺省表情按ID稳定生成 |
| `drops` | 旧日期数组，作为“以前留下的一滴”，保留日期并说明没有附带文字；不再写新的每日计数 |
| `visited` | “使用过”的布尔标记，只改变下次欢迎语，不记录访问次数、时间或时长 |
| `rain-paused` / `weather` | 暂停布尔值及 `rain`、`cloudy`、`sunny` 偏好 |
| `lucky-progress` | 共享幸运进度 `{version:2,misses,daily}`，连续未中次数0～20，`daily` 为最近生成的今日快照或 `null`；兼容旧 `{version:1,hits,misses}`，首次新相遇时迁移。计数与缓存不属于收藏备份 |

新赠言键为 `lucky-everyday:xinxin:v2:gift-drops`：

```js
{
  version: 2,
  items: [
    { id: 'message:rest-01', source: 'message', messageId: 'rest-01', text: '保存时的赠言', expression: 'smile' },
    { id: 'daily:2026-10-19', source: 'daily', day: '2026-10-19', messageId: 'daily-10', text: '当天的赠言快照', expression: 'blank' },
    { id: 'lucky:独立相遇ID', source: 'lucky', messageId: 'super-lucky-01', text: '相遇时的特殊赠言', expression: 'laugh', at: '2026-11-04T03:12:00.000Z', special: 'super-lucky' },
    { id: 'daily:2026-11-04', source: 'daily', day: '2026-11-04', messageId: 'super-lucky-01', text: '当天的特殊赠言快照', expression: 'smile', special: 'super-lucky' }
  ]
}
```

新记录首次成功写入时，把已读取的旧收藏一起转成普通雨滴。旧ID不在内容池时保留ID与 `text: null`，不编造文字。新结构一次写入内容、身份和表情；只要新键存在（包括空数组），就不会再次从旧备份导入。取出不会导致旧记录重新出现。

损坏的新结构或转换前的旧收藏不会被自动覆盖；保存失败不会增加数量。其他存储键独立工作，跨标签页同步当前版本的收集和取出。旧版本页面需刷新后使用新版记录。清理整个网站数据仍可能使所有本地记录消失。

存储键与版本仍为原v2；新增幸运来源及可选 `special` 标记，普通旧记录不需迁移。特殊外观依据保存标记，当前内容池移除或改写特殊文案后仍可原样重读。旧版页面无法识别新幸运来源时会停止写入，需刷新到新版。

## 复制备份与粘贴恢复

“关于这个小地方”提供“复制全部备份”和“粘贴恢复”。备份包含已保存的赠言、今日快照、自己的心事及旧日期记录，保留原文、身份、日期、表情及各类记录的原始顺序；不包含未提交输入、带走的心事、天气或动画偏好。它是明文，请存到自己保管的地方。

备份为缩进的JSON，格式如下；三个数组分别沿用现有赠言、心事、旧日期结构，历史缺省表情仍由原ID稳定生成：

```json
{
  "format": "lucky-xinxin-backup",
  "version": 1,
  "exportedAt": "2026-10-20T03:00:00.000Z",
  "gifts": [],
  "vents": [],
  "legacyDays": []
}
```

点击直接调用剪贴板写入；失败或浏览器不支持时显示可全选的文本，关闭弹窗后清除展示及粘贴内容。恢复由用户粘贴，不自动读取剪贴板；校验完整格式、版本和记录后，显示普通赠言、今日雨滴、自己的心事及旧日期的新增／重复数量，再点击“合并到我的瓶子”。

合并按赠言／心事ID、旧日期去重，同ID保留当前内容，新记录按备份顺序追加；重复恢复不增加数量，不重新导入旧收藏备份。确认前重新读取本地记录，有变化时刷新预览并要求再点一次合并。损坏备份、未知版本或当前记录无法完整读取时停止，不覆盖原记录。

备份版本仍为1，赠言数组完整携带幸运记录的 `source`、`at`、`special`。恢复预览中“超级幸运”统计主动幸运与每日幸运，普通“今日雨滴”不重复计入它们。同一个相遇ID重复恢复会跳过，不同相遇分别保留。

本地存储不支持跨键事务。恢复先保留要写入键的原始值，中途失败时回滚本次写入；回滚不会覆盖检测到的其他标签页新值。写入失败或回滚不完整均显示具体结果并保留粘贴文本，不报告成功。全部处理在本地完成，没有上传。

## 内容与隐私

编辑 `content.js` 维护昵称、赠言、爱称彩蛋、插画提示及未来内容。留言ID必须稳定唯一，不复用于另一句话；保留朋友口吻。“小雨点”称呼馨馨，收集物称“小雨滴”。表情、接住和远行 SVG 在 `art.js`，瓶子绘图与交互在 `app.js`。

`letters` 默认为空；仍支持 `{id,title,unlockAt,text}` 的未来内容，时间必须有明确时区。打开时及保持打开期间每30秒按设备时钟检查。未来正文在公开文件里，日期限制不是加密。

`noindex` 继续保留，但不是权限控制。赠言、插画和未来正文公开可访问，不要提交凭证、真实聊天或需要保密的个人材料。倾诉只存在使用者的本地浏览器；本地记录不是加密保险箱，同一浏览器使用者可能查看。GitHub同域项目共享origin，键名前缀不是项目之间的安全隔离。本站没有账号、上传、通知、消息发送、声音或分析功能。

## 验证

Playwright仅为开发依赖，不参与网页运行：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/browser.cjs
```
